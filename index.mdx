Qyro Engine is a Python runtime framework for building production-ready native apps without boilerplate or CLI lock-in. Mix `ApplicationContext` into any window class to get automatic settings loading, platform detection, resource discovery, and a unified event loop — all in a single `pip install`.

## Get up and running in three steps

<Steps>
  <Step title="Install Qyro Engine">
    Pick the extra that matches your target UI framework and install it with pip.

    ```bash
    pip install "qyro-engine[pyside6]"
    ```
  </Step>
  <Step title="Create settings/base.json">
    Qyro Engine reads your app name, binding, and metadata from a single JSON file at project root.

    ```json
    {
      "app_name": "My First App",
      "binding": "PySide6",
      "version": "1.0.0",
      "author": "Your Name"
    }
    ```
  </Step>
  <Step title="Write your app class and run">
    Mix `ApplicationContext` into your window class and call `exec()` — the rest is automatic.

    ```python
    import sys
    from qyro_engine import ApplicationContext
    from PySide6.QtWidgets import QMainWindow

    class MyApp(QMainWindow, ApplicationContext):
        def __init__(self):
            super().__init__()
            self.setMinimumSize(640, 480)

    if __name__ == "__main__":
        window = MyApp()
        window.show()
        sys.exit(window.exec())
    ```
  </Step>
</Steps>
