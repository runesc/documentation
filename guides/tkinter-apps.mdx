Tkinter ships as part of the Python standard library, which makes it the ideal choice when you want a zero-dependency UI target or need to support environments where installing Qt or Kivy isn't practical. Qyro Engine treats Tkinter as a first-class binding — you get the same settings loading, resource resolution, reactive state, and execution-mode detection that Qt and Kivy users enjoy, with no extras required.

## Install Qyro Engine

The base package includes Tkinter support. No optional extras are needed:

```bash
pip install qyro-engine
```

<Note>
  Tkinter is part of the Python standard library. If `import tkinter` fails on your system, your Python installation may be missing the optional `tk` system package. On Debian/Ubuntu, run `sudo apt install python3-tk` to add it.
</Note>

## Configure Your Binding

Create `settings/base.json` at the root of your project and set `"binding"` to `"tkinter"`:

```json
{
  "binding": "tkinter",
  "app_name": "My Desktop App"
}
```

## Build a Tkinter App

Mix `ApplicationContext` into your `tk.Tk` subclass. Qyro wraps your `__init__` so the engine context, settings, and resource resolver are all ready before your constructor body runs.

```python
import tkinter as tk
from qyro_engine import ApplicationContext


class MyTkApp(tk.Tk, ApplicationContext):
    def __init__(self):
        super().__init__()
        self.title(self.app_settings.get("app_name", "Tkinter Desktop"))
        self.geometry("400x250")

        lbl = tk.Label(self, text=f"Execution mode: {self.execution_mode.value}")
        lbl.pack(pady=40)


if __name__ == "__main__":
    app = MyTkApp()
    app.exec()   # or app.mainloop()
```

<Steps>
  <Step title="Set binding in base.json">
    Add `"binding": "tkinter"` so Qyro loads the Tkinter adapter automatically.
  </Step>
  <Step title="Inherit from tk.Tk and ApplicationContext">
    List `tk.Tk` first in the MRO so Tkinter initialises the root window correctly. `ApplicationContext` cooperatively attaches its engine state before your `__init__` body runs.
  </Step>
  <Step title="Use Qyro APIs inside __init__">
    `self.app_settings`, `self.get_resource()`, `self.execution_mode`, and `self.is_frozen` are available as soon as `super().__init__()` returns.
  </Step>
  <Step title="Start the event loop">
    Call `app.exec()` or `app.mainloop()` — both are equivalent. `exec()` is the Qyro-standard name that works identically across all bindings.
  </Step>
</Steps>

## Event Loop

`ApplicationContext.exec()` is the universal event-loop starter across all Qyro bindings. For Tkinter specifically, it delegates to `mainloop()`. You can call either form:

```python
if __name__ == "__main__":
    app = MyTkApp()
    app.exec()       # Qyro universal form — recommended
    # app.mainloop() # Standard Tkinter form — also works
```

## Settings, Resources, and Execution Mode

All `ApplicationContext` service APIs are available inside your Tkinter app, including:

```python
class MyTkApp(tk.Tk, ApplicationContext):
    def __init__(self):
        super().__init__()

        # Read merged settings from settings/base.json
        app_name = self.app_settings.get("app_name", "My App")
        self.title(app_name)

        # Resolve a bundled image — returns absolute path, works frozen or in source
        icon_path = self.get_resource("icons", "Icon.ico", required=False)
        if icon_path:
            self.iconbitmap(icon_path)

        # Check whether running as a packaged executable
        mode_label = tk.Label(
            self,
            text=f"Mode: {self.execution_mode.value} | Frozen: {self.is_frozen}"
        )
        mode_label.pack(pady=20)
```

<CardGroup cols={2}>
  <Card title="app_settings" icon="gear">
    Dictionary of all merged settings from `settings/base.json` and any OS-specific JSON overrides.
  </Card>
  <Card title="execution_mode" icon="box">
    `ExecutionMode` enum — `SOURCE` in development, `FROZEN_PYINSTALLER` when packaged.
  </Card>
  <Card title="get_resource(*segments)" icon="folder-open">
    Resolves an asset from your `resources/` directory to an absolute path. Works identically in source and frozen builds.
  </Card>
  <Card title="is_frozen" icon="lock">
    Boolean. `True` when the app is running inside a PyInstaller bundle.
  </Card>
</CardGroup>

</Tip>
